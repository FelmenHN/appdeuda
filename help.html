📖 Manual del Sistema de Carteras de Mora

Guía completa de instalación, configuración, uso y mantenimiento · Versión 1.0 · 2025

📋 Descripción general

El Sistema de Carteras de Mora es una solución integral de procesamiento y visualización de datos diseñada para la Municipalidad de San Pedro Sula. Permite consolidar, normalizar y analizar las deudas tributarias distribuidas en 7 carteras de morosidad, generando una base de datos unificada y un dashboard web interactivo publicable en internet.

⚡

ETL Automatizado

Procesa automáticamente los 7 archivos Excel, normaliza los datos y los carga en una base SQLite optimizada.

🗃️

Base de datos SQLite

Base de datos local con índices, vistas preoptimizadas y esquema unificado para consultas rápidas.

📊

Dashboard HTML5

Dashboard web interactivo con gráficos, KPIs y filtros. Funciona sin servidor, solo con un navegador.

🐙

Publicación en GitHub

Soporte integrado para publicar el dashboard en GitHub Pages con un solo clic.

🔄

Actualizable

El sistema está diseñado para ejecutarse periódicamente. Actualice los Excel y regenere la BD en minutos.

📋

Exportación a Excel

Exporte todos los resúmenes y vistas SQL a un archivo Excel con formato profesional.

🚀 Instalación inicial

1

Descomprimir el proyecto

Copie la carpeta CARTERA_MORA en la ubicación de su preferencia (ej: C:\Municipalidad\CARTERA_MORA\).

2

Copiar los archivos Excel

Coloque los 7 archivos de carteras de morosidad en la carpeta datos\.

3

Ejecutar MENU.bat

Haga doble clic en MENU.bat. Se abrirá la consola con el menú principal.

4

Instalar dependencias (Opción 1)

La primera vez, seleccione la opción 1 — Instalar dependencias. Esto instalará automáticamente las librerías Python necesarias.

5

Procesar las carteras (Opción 2)

Seleccione la opción 2 — Procesar carteras para generar la base de datos SQLite por primera vez.

6

Abrir el dashboard (Opción 7)

Seleccione la opción 7 — Abrir dashboard para visualizar los datos en el navegador.

Convenios GM — Forward Fill

En el archivo de Convenios GM, la columna de clave catastral puede tener celdas vacías debajo de un valor. Estas celdas vacías heredan el valor de la clave catastral superior, siguiendo la lógica del reporte original. Este proceso se aplica también a otras columnas con el mismo patrón: sector, barrio, tipo de predio, RMC, nombre, tipo de cargo y años de mora.

🐙 GitHub / Publicación web

El sistema permite publicar el dashboard en GitHub Pages para acceso desde internet sin necesidad de servidor propio.

Requisitos previos

  • Tener Git instalado (git-scm.com)
  • Tener una cuenta en github.com
  • Crear un repositorio vacío en GitHub
  • Generar un Token de acceso personal (PAT)

Cómo generar el Token (PAT)

1

Vaya a github.com → Settings → Developer settings → Personal access tokens → Tokens (classic)

2

Haga clic en Generate new token

3

Seleccione el permiso repo (full control of private repositories)

4

Copie el token generado y guárdelo. Solo se muestra una vez.

Activar GitHub Pages

Después del primer push, vaya a su repositorio → Settings → Pages → Source y seleccione la rama main. El dashboard estará disponible en https://usuario.github.io/repositorio/

Modo Auto-push

Si activa el auto-push, cada vez que ejecute la opción 5 (Actualizar dashboard) el sistema publicará automáticamente los cambios en GitHub Pages sin intervención adicional.

⚠️
Si su repositorio es público, la base de datos SQLite será accesible para cualquier persona. Si los datos son confidenciales, use un repositorio privado y active GitHub Pages solo para colaboradores.

❓ Preguntas frecuentes

¿Con qué frecuencia debo ejecutar el proceso?

Cada vez que reciba nuevos archivos Excel de carteras actualizadas. El sistema regenera la BD completa, por lo que simplemente reemplace los archivos en /datos/ y ejecute la opción 2.

¿Qué pasa si un archivo Excel tiene columnas adicionales o diferentes?

El sistema detecta automáticamente las columnas conocidas y mapea las variantes de nombres. Las columnas desconocidas se descartan (incluyendo columnas sin nombre que genera Excel). Se registra en el log cuántas columnas fueron mapeadas.

¿Puedo agregar una nueva cartera en el futuro?

Sí. Basta con colocar el nuevo archivo Excel en /datos/. Si el nombre del archivo no es reconocido automáticamente, el tributo se registrará como DESCONOCIDO. Para que sea reconocido correctamente, edite la función detectar_tributo() en scripts/normalizar_carteras.py.

¿Los registros duplicados entre carteras se eliminan?

No se eliminan de la tabla principal, ya que una misma clave catastral puede tener deudas legítimas en diferentes tributos y años. La vista v_resumen_por_catastral consolida toda esa información agrupada, mostrando el total acumulado por predio.

¿El dashboard funciona sin internet?

Sí. Al abrir web/index.html localmente, funciona completamente offline. La BD SQLite está embebida en la carpeta web y se carga directamente en el navegador.

🛠️ Solución de errores comunes

ErrorCausa probableSolución
Python no encontrado Python no está en el PATH del sistema Reinstale Python marcando "Add to PATH" o agréguelo manualmente en Variables de entorno.
No se encontraron archivos .xlsx Los archivos no están en la carpeta /datos/ Copie los 7 archivos Excel a la carpeta datos\ del proyecto.
ModuleNotFoundError: No module named 'openpyxl' Librerías no instaladas Ejecute la opción 1 del menú para instalar dependencias.
Claves catastrales en notación científica Excel convierte valores numéricos largos El sistema corrige esto automáticamente. No requiere acción manual.
git: command not found Git no está instalado Descargue e instale Git desde git-scm.com.
Error al publicar en GitHub Token vencido o sin permisos Genere un nuevo token PAT con permisos repo y actualícelo en la opción 6.
Dashboard no muestra datos BD no copiada a la carpeta /web/ Ejecute la opción 5 (Actualizar dashboard) para copiar la BD.
💡
Ante cualquier error, revise el log de la última ejecución usando la opción 8 del menú. Los logs incluyen la traza completa del error para facilitar el diagnóstico.
